# Glossary

Every annotation, library, package and non-obvious Java idiom used in this project, with a one-line explanation and where it first appears. Grouped by topic; updated each phase.

**Phase key:** P1 = bootstrap, P2 = domain model, P3 = security.

---

## 1. Core ideas

| Term | Meaning |
|---|---|
| **Bean** | An object created and managed by Spring, e.g. `AuthService`. By default there is one shared instance (a **singleton**) for the whole app. |
| **Application context** (IoC container) | Spring's registry of beans, built at startup by `SpringApplication.run(...)`. "IoC" (inversion of control) means Spring creates your objects instead of your code calling `new`. |
| **Dependency injection (DI)** | Spring passes a bean the other beans it needs, usually through its **constructor**, matched **by type**. A class with one constructor needs no `@Autowired`. A missing dependency fails at **startup** ("required a bean of type ... that could not be found"). |
| **Constructor injection** | The preferred style: `private final` fields + a constructor (generated by Lombok's `@RequiredArgsConstructor`). Fields can't change, the object can't exist half-built, and unit tests can create it with `new` and fake dependencies. |
| **Component scanning** | At startup Spring searches the main class's package and every package below it for `@Component`-style classes and makes them beans. A class outside `com.example.taskapi` is silently ignored. |
| **Proxy** | A generated wrapper object around a bean. Spring uses proxies to add behaviour around method calls (`@Transactional` starts and commits a transaction) and Spring Data uses them to implement repository interfaces. Only works on beans Spring created, not on objects made with `new`. |
| **Auto-configuration** | Spring Boot creates sensible default beans (data source, Jackson, security) based on what's on the classpath, and backs off when you define your own bean of that type. |
| **Profile** | A named set of configuration (`dev`, `prod`). `application-<profile>.yaml` overrides `application.yaml`. |

## 2. Packages: where an import comes from

| Package prefix | Library |
|---|---|
| `java.*`, `javax.crypto.*` | The JDK itself (`UUID`, `Optional`, `Duration`, `Instant`, `SecretKey`). |
| `jakarta.*` | **Jakarta EE**: standard Java specifications (servlets, Bean Validation, JPA) that Spring and Hibernate implement. Formerly `javax.*`, which is why older tutorials import `javax.persistence` / `javax.servlet`. |
| `org.springframework.*` | Spring Framework, Spring Boot, Spring Security, Spring Data. |
| `org.hibernate.*` | **Hibernate**, the JPA implementation (P2: `@UuidGenerator`). |
| `io.jsonwebtoken.*` | **jjwt**, the JWT library (P3). |
| `lombok.*` | **Lombok**, compile-time code generation. |
| `org.junit.*`, `org.assertj.*`, `org.testcontainers.*`, `com.jayway.jsonpath.*` | Test libraries: JUnit 5, AssertJ, Testcontainers, JsonPath. |
| `com.example.taskapi.*` | Our own code. |

`import static a.b.C.method;` imports a **static method**, so you can call `method()` instead of `C.method()` (used in tests).

## 3. Java language

| Item | Meaning | First used |
|---|---|---|
| `@Override` | This method replaces one from a parent class or interface. The compiler fails if no such method exists, which catches typos. | P3 `UserPrincipal` |
| `record X(A a, B b)` | Immutable data class. Java generates the constructor, accessors `a()` / `b()`, `equals`, `hashCode` and `toString`. | P3 `JwtProperties`, DTOs |
| `enum` | A fixed set of named values (`ADMIN`, `MANAGER`, `USER`). | P2 `Role` |
| Nested `private enum` | An enum visible only inside its class. | P3 `JwtTokenProvider.TokenType` |
| Static factory method (`from(...)`, `bearer(...)`) | A named alternative to a constructor. `UserPrincipal.from(user)` reads better than five constructor arguments. | P3 |
| `private` constructor + `final class` | Nobody can create or subclass it: a holder of `static` methods only. | P3 `TenantContext` |
| `static final` constant | One shared value per class that can't change. Named in `UPPER_SNAKE_CASE`. | P3 `BEARER_PREFIX` |
| `abstract class` | Can't be instantiated itself, only extended. | P2 `BaseEntity` |
| Generics `<T extends TenantScopedEntity>` | A type parameter limited to `TenantScopedEntity` or its subclasses. | P2 `TenantScopedRepository` |
| `ThreadLocal<T>` | A variable where each thread sees its own value. Must be cleared when threads are reused. | P3 `TenantContext` |
| Checked exception / `throws X` | Java forces callers to handle or re-declare it, e.g. `IOException`. `HttpSecurity.build()` declares `throws Exception`, so our `@Bean` method passes it on. | P3 `SecurityConfig` |
| Unchecked exception (`extends RuntimeException`) | No `throws` needed anywhere. Spring prefers these. | P3 `DuplicateResourceException` |
| `try { ... } finally { ... }` | `finally` runs whether the `try` succeeds or throws. Used to always clear `TenantContext`. | P3 filter |
| `var` | The compiler works out the type. Still strictly typed, just shorter. | P3 filter |
| Lambda `x -> ...` | A function passed as an argument: `csrf -> csrf.disable()`. | P3 `SecurityConfig` |
| Method reference `Class::method` | Short form of a lambda: `UserPrincipal::from` = `user -> UserPrincipal.from(user)`. With Spring 7, prefer lambdas for Spring methods (see §12). | P3 |
| Pattern-matching `instanceof` | `if (x instanceof UserPrincipal p)` checks the type **and** declares `p` already cast. `false` for `null`. | P3 `JpaAuditingConfig` |
| Text block `"""..."""` + `.formatted(...)` | Multi-line string (Java 15+). `%s` placeholders are filled by `.formatted(a, b)`, like `String.format`. | P3 tests |
| `Optional<T>` | A box that may be empty, used instead of returning `null`. `.orElseThrow(() -> new X())` returns the value or throws. `.map(...)` transforms it if present. | P2 repositories |
| `Duration` / `Instant` / `Date` | `Duration` = a length of time (15 min). `Instant` = a moment in UTC. `Date` = the pre-Java-8 type, still required by jjwt (`Date.from(instant)`). | P2 / P3 |
| `UUID` | A 128-bit unique id. We use time-ordered **UUIDv7** for primary keys. | P2 |
| `Locale.ROOT` | A language-neutral locale for `toLowerCase`, so results don't depend on the server's language (Turkish `I` → `ı`). | P3 `AuthService` |
| `package-info.java` | A file describing a package (Javadoc). Also keeps empty folders in Git. | P1 |
| `/** ... */` | Javadoc comment, shown by IDEs on hover. | P1 |

## 4. Lombok (`lombok.*`)

Lombok generates code **at compile time**: it's in the `.class` file, not the `.java` file. Inspect with `javap -p -cp target/classes <class>`.

| Annotation | Generates | First used |
|---|---|---|
| `@Getter` / `@Setter` | `getX()` / `setX()` for each field. | P2 entities |
| `@RequiredArgsConstructor` | A constructor for every `final` field, which Spring uses for dependency injection. | P3 services |

We avoid `@Data`, because it builds `equals`/`hashCode` from every field, which breaks JPA entities (see `phase-2-domain-model.md` §3.2).

## 5. Spring core & Spring Boot

| Item | Meaning | First used |
|---|---|---|
| `@SpringBootApplication` | Turns on component scanning, auto-configuration and configuration support for the main class's package tree. | P1 |
| `SpringApplication.run(...)` | Starts the app: builds the application context, starts Tomcat. | P1 |
| `@Component` | "Make this class a bean." The general form of the annotations below. | P3 `JwtTokenProvider` |
| `@Service` | A `@Component` holding business logic. | P3 `AuthService` |
| `@RestController` | A `@Component` handling HTTP requests; return values become JSON (`@Controller` + `@ResponseBody`). | P3 `AuthController` |
| `@Configuration` | A class that defines beans through `@Bean` methods. | P2 `JpaAuditingConfig` |
| `proxyBeanMethods = false` | Skip generating a subclass of the `@Configuration` class. That subclass only matters if one `@Bean` method calls another; ours don't, so startup is slightly faster. | P2 |
| `@Bean` | "Call this method at startup and register what it returns as a bean." Its parameters are injected. | P2 `auditorAware()` |
| `@Autowired` | Inject a bean into a field or parameter. Only needed in our tests (JUnit creates test classes, so no constructor injection). | P2 tests |
| `@ConfigurationProperties(prefix = "app.jwt")` | Binds YAML keys under `app.jwt` to a record's components (`access-token-ttl` → `accessTokenTtl`, `15m` → `Duration`). | P3 `JwtProperties` |
| `@ConfigurationPropertiesScan` | Finds `@ConfigurationProperties` classes and makes them beans. | P3 main class |
| `@Validated` on properties | Runs Bean Validation (`@NotBlank` ...) on configuration at startup; a failure stops the app. | P3 `JwtProperties` |
| `${VAR:default}` in YAML | Use environment variable `VAR`, else `default`. Without `:default`, startup fails if it's missing. | P1 |
| `spring.profiles.default` | Profile used when none is chosen with `SPRING_PROFILES_ACTIVE`. | P1 |

## 6. Web: Spring MVC & servlets

**Servlet** = Java's standard API for HTTP (`jakarta.servlet`). **Tomcat** runs servlets; Spring Boot embeds it. Spring MVC is one servlet, `DispatcherServlet`, that routes requests to controller methods.

| Item | Meaning | First used |
|---|---|---|
| `@RequestMapping("/api/auth")` | Path prefix for every method in the controller. | P3 |
| `@PostMapping` / `@GetMapping` / `@DeleteMapping` | Handle that HTTP method on that path. | P3 |
| `@RequestBody` | Build the parameter from the JSON body (converted by **Jackson**, Spring's JSON library). | P3 |
| `@Valid` | Run the parameter's Bean Validation rules; any failure → **400**. | P3 |
| `@ResponseStatus(...)` | On a method: the success status (e.g. 201). On an exception class: the status when it's thrown. | P3 |
| `HttpStatus`, `HttpHeaders`, `MediaType` | Constant holders, e.g. `HttpHeaders.AUTHORIZATION` instead of the string `"Authorization"`. | P3 |
| `HttpServletRequest` / `HttpServletResponse` | The raw request (headers, body, path) and raw response. | P3 filter |
| Filter / `FilterChain.doFilter(...)` | Filters run in a chain before the servlet. `doFilter` passes the request on; code before it runs on the way in, code after it on the way out. | P3 filter |
| `OncePerRequestFilter` | Spring base class guaranteeing a filter runs once per request; implement `doFilterInternal`. | P3 filter |
| `/error` | Spring Boot's error page. On an error, the request is forwarded there to build the JSON error body. | P3 `SecurityConfig` |
| Status codes | 200 OK · 201 Created · 400 Bad Request (invalid input) · 401 Unauthorized (not logged in) · 403 Forbidden (logged in, not allowed) · 404 Not Found · 409 Conflict (clashes with existing data). | P3 |

## 7. Bean Validation (`jakarta.validation.constraints`)

| Annotation | Rule | First used |
|---|---|---|
| `@NotBlank` | Not null, not empty, not only spaces (strings). | P3 DTOs |
| `@NotNull` | Not null (any type). | P3 `JwtProperties` |
| `@Email` | Looks like an email address. | P3 DTOs |
| `@Size(min, max)` | String length range. | P3 DTOs |

## 8. Spring Security

| Item | Meaning | First used |
|---|---|---|
| `SecurityFilterChain` | The ordered list of security filters plus the URL rules, applied to every request. | P3 |
| `HttpSecurity` | A **builder** for the chain: each `.csrf(...)`, `.sessionManagement(...)` call configures one part; `http.build()` produces the chain. | P3 |
| `authorizeHttpRequests` / `requestMatchers(...)` | URL rules, checked top to bottom, first match wins: `permitAll()`, `authenticated()`, `hasRole("ADMIN")`, `hasAnyRole(...)`. | P3 |
| CSRF | Cross-Site Request Forgery: an attack using cookies the browser sends automatically. Disabled because we use a header, not cookies. | P3 |
| `SessionCreationPolicy.STATELESS` | Never create or use an HTTP session; every request brings its own JWT. | P3 |
| Authentication entry point / `HttpStatusEntryPoint` | What to send when a not-logged-in user hits a protected URL; ours sends 401. | P3 |
| `addFilterBefore(filter, X.class)` | Insert our filter before filter `X` in the chain. `UsernamePasswordAuthenticationFilter` (form login, unused by us) is only a position marker. | P3 |
| `SecurityContextHolder` | Spring Security's per-thread store of the current `Authentication`. Read by `hasRole`, `@AuthenticationPrincipal`, `AuditorAware`. | P3 |
| `Authentication` / principal | "Who is calling, with which authorities." The **principal** is the user object (our `UserPrincipal`). | P3 |
| `UsernamePasswordAuthenticationToken` | An `Authentication`. `.unauthenticated(email, password)` = credentials to check; `.authenticated(principal, null, authorities)` = verified user. | P3 |
| `GrantedAuthority` / `SimpleGrantedAuthority` | A permission string such as `ROLE_ADMIN`. `hasRole("ADMIN")` checks for the `ROLE_` prefix. | P3 |
| `UserDetails` / `UserDetailsService` | "A user Spring Security can check" / "how to load one by username". | P3 |
| `AuthenticationManager` / `ProviderManager` / `DaoAuthenticationProvider` | The "check these credentials" service, its standard implementation, and the provider that loads the user and compares the BCrypt hash. | P3 |
| `PasswordEncoder` / `BCryptPasswordEncoder` | One-way, salted, deliberately slow password hashing. Hashes look like `$2a$10$...` (version, cost factor 2¹⁰). | P3 |
| `AuthenticationException` and subclasses | Login failures (`BadCredentialsException`, `UsernameNotFoundException`, our `InvalidTokenException`); turned into 401. | P3 |
| `@AuthenticationPrincipal` | Inject the logged-in principal into a controller method parameter. | P3 tests |

## 9. JWT: jjwt (`io.jsonwebtoken`)

| Item | Meaning | First used |
|---|---|---|
| JWT | `header.payload.signature`, Base64url-encoded. The payload is **readable by anyone**; the signature (HMAC-SHA256 with our secret) makes it tamper-proof. | P3 |
| Claims | The payload fields: `sub`, `org`, `role`, `email`, `type`, `iat`, `exp`. | P3 |
| `Jwts.builder()...signWith(key).compact()` | Build and sign a token; `compact()` returns the `xxx.yyy.zzz` string. | P3 |
| `Jwts.parser().verifyWith(key).build().parseSignedClaims(token).getPayload()` | Parse, verify signature and expiry, return `Claims`. | P3 |
| `Claims.getSubject()` / `get("org", String.class)` | Read standard / custom claims. | P3 |
| `Keys.hmacShaKeyFor(bytes)` / `Decoders.BASE64` | Turn the Base64 secret into a `SecretKey`; fails if under 256 bits. | P3 |
| `JwtException` | Parent of every jjwt failure (expired, bad signature, malformed). | P3 |
| Access vs refresh token | Short-lived (15 min) token for every request vs long-lived (7 d) token used only to get new tokens. See `phase-3-security.md` §3.2. | P3 |

## 10. Persistence: JPA, Hibernate, Spring Data, Flyway

| Item | Meaning | First used |
|---|---|---|
| **JPA** (`jakarta.persistence`) | The standard Java API for mapping objects to tables. **Hibernate** implements it. | P2 |
| `@Entity` / `@Table(name = ...)` | This class is a table row; which table. | P2 |
| `@Id` | The primary key field. | P2 |
| `@UuidGenerator(style = VERSION_7)` | Hibernate generates a time-ordered UUID when the entity is first saved. | P2 |
| `@Column(name, nullable, updatable, unique)` | Column mapping. `updatable = false` leaves the column out of `UPDATE`. | P2 |
| `@Enumerated(EnumType.STRING)` | Store an enum by name (`"ADMIN"`), not by position. | P2 |
| `@ManyToOne(fetch = LAZY)` / `@JoinColumn` | Many tasks point to one project; load it only when accessed; which foreign key column. | P2 `Task` |
| `@MappedSuperclass` | "Not a table; copy my fields into each child entity's table." | P2 `BaseEntity` |
| `@EntityListeners(AuditingEntityListener.class)` | Run Spring Data's auditing before insert/update. | P2 |
| `@EnableJpaAuditing` + `@CreatedDate` / `@LastModifiedDate` / `@CreatedBy` | Fill audit fields automatically. | P2 |
| `AuditorAware<T>` | Answers "who is the current user?" for `@CreatedBy`. | P2 / P3 |
| Spring Data repository | An **interface**; Spring Data generates the implementation (a proxy) at startup. | P2 |
| `Repository<T, ID>` | Empty marker interface: only the methods we declare exist. (`JpaRepository` would add unscoped `findAll` etc.) | P2 |
| Derived query (`findByIdAndOrganizationId`) | SQL generated from the method name; a typo fails at startup. | P2 |
| `@NoRepositoryBean` | "Don't create a bean for this base interface." | P2 |
| `Pageable` / `Page<T>` | Page number, size and sort in; rows plus total counts out. | P2 |
| `@Transactional` | Run the method in one database transaction: all statements commit together or roll back together. Added by a proxy. | P3 `AuthService` |
| `@Transactional(readOnly = true)` | A transaction that only reads; Hibernate skips checking for changes to save. | P3 |
| `ddl-auto: validate` | Hibernate only checks entities against tables, never changes the schema. | P1 |
| `open-in-view: false` | No database connection held for the whole HTTP request. | P1 |
| **Flyway** / `V1__name.sql` | Versioned SQL migrations, run in order at startup and recorded in `flyway_schema_history`. Never edit one that has run. | P1 |

## 12. Editor null-safety warnings (Spring 7 + JSpecify)

Spring 7 marks APIs with **JSpecify** annotations (`@NullMarked` packages, `@Nullable` values). VS Code warns ("needs unchecked conversion to conform to '@NonNull ...'") when a **method reference** to a Spring method is passed into unannotated JDK generics such as `Optional.map`. These are editor hints, not compile errors. Fix: use a lambda, or an explicit null check / pattern-matching `instanceof`.
